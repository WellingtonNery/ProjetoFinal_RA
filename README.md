# 100 DAYS OF SHOGUN

## Sobre o projeto

100 DAYS OF SHOGUN é um jogo indie 2D desenvolvido em Python com uso da biblioteca Pygame inspirado no estilo de jogo Reigns. O jogador controla um governante em Takayama na era feudal, tomando decisões que afetarão diretamente o seu reinado com base nos medidores de contentamento do povo, população e dinheiro. 

## Objetivos do jogo

O objetivo do jogador é acumular o máximo de pontos possíveis até chegar na era de ouro, mas para isso será necessário um preciso controle da sua pontuação, se os medidores forem muito baixos o jogador poderá ser deposto do cargo, sofrer um golpe ou até mesmo ser executado.

## Funcionalidades

- Eventos aleatórios;
- Interação com NPCs;
- Escolhas com consequências;
- Gerenciamento de recursos;
- Finais alternativos;
- Sistema de passagem de dias;

## Tecnologias utilizadas

- Python
- Pygame
- Pixel art para sprites, cenários e interface.
